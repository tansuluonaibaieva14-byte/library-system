# Use Case

## Жүйе пайдаланушылары

### Оқырман
Оқырман кітаптарды іздейді және кітап туралы ақпаратты қарайды.

### Кітапханашы
Кітапханашы кітаптарды тіркейді және кітаптардың берілуін бақылайды.

## Негізгі әрекеттер

1. Жүйеге кіру
2. Кітаптарды іздеу
3. Кітап туралы ақпаратты көру
4. Кітапты тіркеу
5. Кітап беру
6. Кітапты қайтару
